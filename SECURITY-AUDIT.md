# Проверка публичных исходников

Дата: 1 ноября 2026 года. Проект: **GNOME PR Indicator**.

## Проверено

- Все публикуемые файлы, включая код, тесты, документацию и схему настроек.
- Публикуемая история Git и метаданные коммитов.
- Отсутствие личного имени репозитория, прежнего UUID и локальных путей пользователя в публикуемых файлах.
- Форматы GitHub/API-токенов, закрытых ключей и встроенных паролей.
- Отсутствие .env, файлов учётных данных и связок ключей в составе проекта.

## Хранение токена

`lib/secrets.js` использует libsecret / GNOME Keyring. `prefs.js` передаёт введённый токен в связку ключей и очищает поле. `lib/github.js` получает токен во время работы; значение токена в исходниках отсутствует.

Тесты используют вымышленные строки. URL `https://user:pass@github.com/a` в `tests/model.test.js` проверяет запрет ссылок со встроенными учётными данными и не содержит пользовательского пароля.

## Нейтральные значения

- UUID расширения: `gnome-pr-indicator@extensions.local`.
- Схема настроек: `org.gnome.shell.extensions.gnome-pr-indicator`.
- Репозиторий: `owner/repository` — шаблон, который пользователь заменяет в настройках.
- Файл установки: `gnome-pr-indicator@extensions.local.zip`.

Пользовательские параметры и токены не включаются в репозиторий. Поиск по форматам дополняет просмотр кода, но не является математической гарантией отсутствия любого возможного секрета.
